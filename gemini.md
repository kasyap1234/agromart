# AgroMart Project Architecture

## Overview
AgroMart is a web application built with:
- Next.js (Frontend)
- Go Echo (Backend)
- Caddy (Reverse Proxy)

## Frontend (Next.js)
- Modern React framework for server-side rendering
- Built-in routing and API routes
- TypeScript support
- Pages directory structure
- API integration with Go backend

## Backend (Go Echo)
- Lightweight and fast web framework
- RESTful API endpoints
- Middleware support
- Database integration
- JWT authentication

## Reverse Proxy (Caddy)
- Automatic HTTPS
- Load balancing
- Routing rules
- SSL/TLS termination
- Gzip compression
